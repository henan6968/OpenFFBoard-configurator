feat(i18n): finish the Simplified Chinese translation

The menus were Chinese but most of the pages were not. Two causes, both
silent:

* translations/zh_CN.ts already had plenty of Chinese, but zh_CN.qm - which is
  what the application actually loads - was compiled on 2026-09-10 and never
  rebuilt after the .ts changed. A stale .qm just shows English; nothing
  errors.
* The .ts was last translated before the Axis page, the remote CAN and RMD
  pages, the signature dialogs and the VescUART tab existed, so all of those
  entries were "unfinished" English placeholders.

Filled 66 entries, including the three the user asked about:
  Permanent damper  -> 永久阻尼   (always-on damper, speed dependent)
  Permanent inertia -> 永久惯量   (always-on inertia, acceleration dependent)
  Permanent friction-> 永久摩擦力 (always-on, speed independent)
plus the Axis torque curve dialog, the remote CAN source page, the ODrive and
RMD pages, the TMC4671 openloop dialog and its high-current warning, the
signature dialogs, About, and the connection status shown in the status bar.

Also fixed what made those strings untranslatable in the first place:

* 18 dialog titles were plain setWindowTitle("...") literals, which are never
  extracted. Wrapped in self.tr().
* The VescUART help text was a module level constant passed to self.tr(); the
  extractor only sees literal arguments, so it could never be translated. The
  HTML is inline in the tr() call now.
* "Current" means amps on the TMC openloop page and "present" on the shifter
  button page. pylupdate6 recycles one translation across contexts, so a
  context override keeps them apart.

Tools: translations/tool_report_untranslated.py lists what is missing,
tool_dump_untranslated.py exports it as JSON, tool_fill_zh_cn.py applies the
translation table, and tools/check_zh_cn_ui.py prints the widget texts with
zh_CN installed.

Tests: tests/test_translation_zh_cn.py (10 cases). The important one asserts
the .qm is not older than the .ts, which is the failure that hid all of this.
Full suite: 61 tests pass.
